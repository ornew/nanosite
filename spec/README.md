## Conventions

MUST and MUST NOT express requirements. SHOULD expresses a recommendation.
MAY expresses an allowed choice. Label proposed behavior explicitly.
Examples illustrate contracts; pseudocode must be labeled as such.

## Implementation status

State which contracts are implemented for each backend, platform or API.
Separate planned behavior from released behavior. Record version gates and
unsupported operations explicitly rather than promising universal support.
